# Release history

All dates below use Tehran time (UTC+3:30). Development began on 11 November 2026. Git history starts with the truthful import on 13 November. Earlier local versions are documented milestones, not invented Git commits or backdated releases. A version number measures the software contract, not time spent or competition standing.

## 1.0.0 · 13 November 2026

### Added

- A documented investigation-format compatibility contract and clear separation between app and method versions.
- A 29-second, silent English-captioned video using actual retained data charts, with visible AI assistance and start-date disclosure.
- An updated seven-slide PDF and public video page with captions, transcript and direct downloads.
- A Farhad review guide, evidence-based rubric, student practice tasks and a checksummed handoff archive with tracked source and a frozen local demonstration.

### Changed

- Release packaging verifies public media and all forty analyses, in addition to the existing source and asset checks.
- The complete saved-investigation workflow graduates from 0.4 to its documented 1.x contract after browser, clean-environment and release checks.
- No statistical method or NASA observations are replaced. No existing export format is removed.

### Verification and limits

All 83 tests pass locally. The preceding 81-test suite also passed in a clean macOS environment. Browser tests cover period selection, notes, saving, restoration, file import, download and printing. The public deployment evidence is recorded separately after deployment. The video is 29.00 seconds with 696 frames, fully decoded and visually reviewed. All seven PDF pages were reviewed. The software milestone is complete; the documented scientific, user-testing and organizer checks remain open.

## 0.4.0 · 13 November 2026

### Added

- Four fixed periods ending in 2025 for every public location and variable. Forty complete analyses can be inspected and replayed without a NASA request.
- All four period rates together, so a reader can see date sensitivity without searching for a preferred p-value.
- Saved JSON import with file-size, schema, source endpoint, hash, calendar aggregation and slope checks in the browser.
- Optional browser-local saving, explicit restore and clear controls, and investigation printing.
- Tests for every frozen period, changed evidence, malicious text, storage errors and asynchronous saves.

### Changed

- Public dates are selectable fixed periods instead of a single disabled 1981–2025 choice. The longest period remains the default.
- User notes can survive reload when local saving is enabled. They are never sent to the app server. Saving is off by default on each page load; a saved copy remains until explicitly cleared.
- Errors distinguish the hosted demonstration from the local Python service.

### Limits

Browser checks do not recalculate confidence intervals, p-values, residual correlation or uncertainty bands. Full numerical replay remains a Python operation. Imports do not authenticate NASA, assess notes or establish scientific correctness. Four overlapping periods are not independent observations or a test of acceleration.

## 0.3.0 · 13 November 2026 · first public GitHub release

Added a public frozen demonstration, source comparisons in the investigation flow, Toronto spatial diagnostics, a worksheet export, dedicated repository, locked dependencies, CI and a seven-page PDF. Fifty-four tests passed locally and on Linux. All ten original public analyses replayed anonymously.

The first CI run failed because a YAML command needed quoting. A build-manifest error then included hidden deployment files that were not publicly accessible. Both were corrected, and the successful public checks were retained. Neither failure is described as a passed check.

## 0.2.1 · 12 November 2026 · local milestone

Fixed payload hashes across Python and browser JSON round trips by normalizing integral numbers, including negative zero. Actual Chrome export and offline replay passed. Statistical settings remain version 0.2.1 in later app releases because those calculations have not been silently replaced.

## 0.2.0 · 11–12 November 2026 · local milestone

Added conditional Newey-West interval comparisons, Theil-Sen slope, influence and date checks, a fixed synthetic evaluation, GISTEMP comparison and replay. The experiment used 20,000 synthetic records. No deployable interval candidate passed every screening case. A real browser round trip exposed a source-hash defect, fixed in 0.2.1. The failed export remains labelled historical evidence.

## 0.1 · 11 November 2026 · local milestone

Initial NASA POWER prototype with location and variable controls, annual and monthly views and CSV/JSON/SVG exports. The original archive is retained locally. Its public manifest preserves its hash; the archive itself contains a local account path and is excluded from publication.
