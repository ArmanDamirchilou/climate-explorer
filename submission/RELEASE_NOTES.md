# Climate Explorer 0.3.0

A shareable research prototype for testing historical climate claims with NASA data. The public demonstration contains temperature and precipitation for five frozen locations, 1981–2025. The Python application also supports custom coordinates and dates.

The release adds source comparisons and a Toronto spatial diagnostic to the existing method and date checks. An investigation worksheet combines user notes with the exact displayed evidence. CSV downloads now preserve that displayed record. Frozen analysis exports support offline replay.

Three specialist Codex agents reviewed science, engineering and submission strategy. Their work is documented in AI_ASSISTANCE.md. The repository includes locked dependencies, numerical and HTTP tests, a network-free demo build, GitHub Actions, a seven-page PDF demonstration and source acknowledgments under an explicit code license.

Development began 11 November 2026, before the hackathon. Codex contributed the approach as well as implementation. Eligibility under the event's early-work and AI-ideation rules remains unresolved. This release is not a competition submission or an award claim. Educational impact and station validation have not been established.
