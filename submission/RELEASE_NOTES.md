# Climate Explorer 1.0.0

A complete saved-investigation workflow for questioning historical climate claims with real NASA data. This release adds a documented 1.x compatibility contract to the 0.4 workflow, plus the review media and handoff package.

- Forty frozen analyses: five locations, two variables and four fixed periods, with all four rates shown together.
- Saved JSON import, optional local notes, restore, clear and printing. Notes stay on the user's device.
- Browser checks of source hashes, calendar aggregation and point estimates. Full Python replay also verifies recorded uncertainty calculations.
- A public 29-second captioned video, seven-slide PDF, Farhad review guide, student practice tasks and checksummed source/demo handoff ZIP.
- Version-by-version history in CHANGELOG.md, preserved Git tags and explicit AI assistance documentation. No AI commit co-author trailers.

Eighty-three tests pass locally. The release verification record links the exact Linux and anonymous public checks. Scientific assumptions and known source discrepancies remain explicit. This release does not claim measured educational impact or station validation.

Development began 11 November 2026, before the event, and Codex contributed the solution approach. Organizer guidance on early-work and AI-ideation eligibility remains necessary. No competition entry or message to Farhad has been submitted by the assistant.
