# Climate Explorer final checks

This checklist cannot make an ineligible project eligible. The student owns registration and final submission under the folder instructions.

## Organizer and student actions

- [ ] Obtain clear organizer guidance on the recorded 11 November start and Codex's contribution to the solution idea. Preserve the reply.
- [x] Map the full production challenge statement and resources to the implementation. Core scope is covered; this does not resolve entry eligibility.
- [ ] Confirm actual team membership, official challenge choice, Ankara acceptance and virtual participation type.
- [ ] Resolve age and guardian requirements. No minor's photo, voice or likeness appears in the proposed demo.
- [ ] Confirm Ankara's latest online delivery link, local deadline and any local pitch requirement.
- [ ] Run the prepared task with real students or teachers if feasible. Keep anonymous observations. Do not invent endorsements or results.
- [ ] Review the implementation and explain the core calculations in the student's own words.

## Release preparation

- [ ] The final repository has an explicit code license and source/dependency acknowledgments.
- [ ] No credentials, private account information, unrelated folder documents, or environment files are published.
- [ ] The published release states that it began on 11 November and identifies AI contributions.
- [ ] All release tests and replay checks pass. Record the exact commit and environment.
- [ ] The public demo clearly distinguishes frozen examples from live NASA requests.
- [ ] The final source and demo links open without login in a signed-out browser.
- [ ] Actual screenshots, current dataset values and current validation findings appear in the demo.
- [ ] The deck has no more than seven slides, or the video lasts no more than 30 seconds. English requirements are met.
- [ ] AI-generated media, if introduced later, have the indicators required by the guide. No NASA branding is generated or modified.
