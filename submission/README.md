# Climate Explorer submission preparation

Prepared 13 November 2026. This package describes a working prototype and prepares the materials for review. It does not establish eligibility or submit an entry.

The strongest story is a climate investigation that exposes uncertainty. A student can inspect a historical trend, change reasonable analysis assumptions, and save the evidence needed to repeat the result. A disagreement is a finding to investigate, rather than something to hide.

Two rules need an organizer's decision before this can be treated as an eligible competition entry. Development began on 11 November, before the event. Codex also helped develop the solution approach, beyond writing code. The current official FAQ and submission guide restrict these activities. Preserve the history and disclose both. See [requirements](REQUIREMENTS.md) and the [organizer message](ORGANIZER_MESSAGE.md).

## Review priorities

| Priority | What would make the project more convincing | Evidence required |
|---|---|---|
| 1 | A valid, honest entry | Organizer guidance on early work and AI ideation; confirmed team and challenge selection |
| 2 | A clear benefit for one audience | Actual students or teachers complete the prepared task; report observed errors and improvements |
| 3 | A complete demonstration | A public, readable demo within the official limit and a final-project link that opens without login |
| 4 | Evidence behind the calculations | Retained source data, numerical checks, method comparison, reproducible exports |
| 5 | A defensible distinctive contribution | Explain how method, period, and source checks improve a student's investigation compared with a chart alone |

If organizers do not permit this prototype as a judged entry, preserve it as a portfolio project and ask whether a noncompetitive demonstration is possible. A new repository, new title, or rewritten code would not change the actual history.
