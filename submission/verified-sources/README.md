## Submission guide

[Production source](https://www.spaceappschallenge.org/resources/project-submission-guide/), dated 12 November 2026.

The form asks for project name, summary, demo link, final-project link, detailed description, AI use, NASA data, and other references. The demo limit is a 30-second video or seven-slide deck. English is required, with subtitled speech permitted for video. Shared links must open without login. Minor likenesses are prohibited. Code and data need AI acknowledgments where generated; generated media have additional indicators.

Its restriction on AI supplying the solution idea is material to this project. The short exact clause is retained in REQUIREMENTS.md.

## Judging guide

[Production source](https://www.spaceappschallenge.org/resources/judging-awards-guide/), dated 12 November 2026.

It scores Impact, Creativity, Validity, Relevance and Presentation from 1 to 5. It confirms team and submission eligibility and multiple global award categories. It does not state a single overall first-place prize. The current project should emphasize demonstrated science and data work while identifying unmeasured impact.
