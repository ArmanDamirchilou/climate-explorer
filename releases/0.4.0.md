# Climate Explorer 0.4.0

The public investigation now includes four fixed periods for every preset and variable, with all four rates shown together. Saved analysis and investigation files can be reopened in the browser. Optional local saving and explicit restore/clear controls keep notes on the user's device. Printing includes the evidence and notes.

Browser verification checks source hashes, calendar aggregation and point estimates. It does not recompute uncertainty intervals, p-values, residual correlation or bands. Python replay remains the complete numerical check.

The release retains the longest-period default, existing method assumptions and truthful development history. No NASA submission, human usability result or scientific certification is claimed. Early-work and AI-ideation eligibility remain unresolved.

See CHANGELOG.md for the version-by-version history and AI_ASSISTANCE.md for assistance. Git commits omit AI co-author trailers at the student's request.
